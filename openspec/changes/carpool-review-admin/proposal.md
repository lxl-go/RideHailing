# 工单01 顺风车管理 — Admin 审核模块

## 开发范围
Admin 端顺风车司机审核管理：司机认证审核 CRUD + 车辆审核 CRUD

## 功能点清单
1. 认证审核列表（分页+状态筛选）
2. 认证审核详情
3. 审核通过操作
4. 审核驳回操作（必填原因）
5. 车辆审核列表
6. 车辆审核操作（通过/驳回）

## 验收标准
- 列表支持分页、状态筛选、关键字搜索
- 审核通过后状态变更为 `status=1`，记录审核人 ID
- 审核驳回时 `status=2`，`reject_reason` 必填
- 车辆审核操作记录操作日志
- 所有接口返回统一格式 `{"code":0,"data":{},"msg":"成功"}`
