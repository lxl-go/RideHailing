# 网约车最终验收口径

### **一、管理后台：12 个业务模块**

| 模块                      | 对应工单 | 必须实现的功能接口                                           |
| ------------------------- | -------- | ------------------------------------------------------------ |
| 顺风车行程管理 `trip`     | WO01     | 行程列表、行程详情、行程下架/停用                            |
| 审核管理 `review`         | WO01     | 认证审核列表、详情、通过、驳回、车辆审核列表、车辆审核处理   |
| 班车管理 `shuttle`        | WO02     | 班线新增、编辑、列表、详情、发布、导出；站点排重、按时间排序、首站时间校验 |
| 财务管理 `finance`        | WO03     | 流水列表、退款流水、财务汇总、异常交易、导出；还应补自动账单、线路结算 |
| 订单管理 `order`          | WO04     | 订单列表、详情、历史、退款申请、退款审核、批量退款、导出；若工单要求自动审核，还要补规则 |
| 人员管理 `person`         | WO05     | 人员列表、详情、新增、编辑、角色分配、批量状态、司机批量删除、导入预览、导入提交、错误列表、导出 |
| 数据分析 `analytics`      | WO06     | 仪表盘、订单量、分类统计、转化率、复购率、导出；若要求点击流，要补前端埋点和采集接口 |
| 营销管理 `marketing`      | WO07     | 券模板、发券、核销、模板删除校验、用户券、活动列表、推荐汇总、导出 |
| 性能分析 `performance`    | WO08     | 运行时快照、报告生成、报告列表、场景列表、汇总、导出；还应补 pprof/trace/expvar/gops/火焰图能力 |
| GVA 治理 `gva_governance` | WO09     | 路由快照、菜单/路由治理、数据源快照、审计快照、定时任务快照、导出；XxlJob/多数据源要单独验收 |
| AI 助手运营 `ai`          | WO10     | AI 对话、雨天路线、带路线对话、水情上报、水情审核、汇总、会话日志、路线日志、水情列表、导出、公开路线信息 |
| 派单中心 `dispatch`       | WO11     | 订单列表、详情、取消派单、改派、司机评分、策略保存、配置列表、发布、回滚、审计、轨迹回放、导出 |

### **二、乘客端：建议定 9 个功能模块**

| 模块                        | 对应工单  | 必须实现的功能接口                       |
| --------------------------- | --------- | ---------------------------------------- |
| 认证登录 `auth`             | WO01      | 发短信、登录、刷新 token、退出           |
| 乘客资料/实名认证 `profile` | WO01      | 我的资料、编辑资料、提交实名、实名状态   |
| 行程搜索 `trip`             | WO01      | 行程搜索、行程详情                       |
| 顺风车订单 `order`          | WO01/WO11 | 下单、取消、订单列表、订单详情、订单轨迹 |
| 退款中心 `refund`           | WO04      | 退款申请、退款进度、退款记录/详情        |
| 评价 `review`               | WO01      | 提交评价、我的评价                       |
| 安全与分享 `safety/share`   | WO01      | 行程分享、紧急求助、特殊需求、保险信息   |
| AI 出行助手 `ai`            | WO10      | AI 对话、雨天路线、带路线对话、水情上报  |
| 优惠券/营销 `coupon`        | WO07      | 我的券、可领券、领券、券使用记录         |

班车车票 `ticket` 如果工单只要求页面占位，可以不计入后端验收；如果要按生产功能验收，就应补：班线查询、班次查询、购票、退票、车票列表、车票详情。

### **三、司机端：建议定 9 个功能模块**

| 模块                              | 对应工单  | 必须实现的功能接口                                           |
| --------------------------------- | --------- | ------------------------------------------------------------ |
| 认证登录 `auth`                   | WO01      | 发短信、登录、刷新 token、退出                               |
| 司机资料/实名认证 `driverProfile` | WO01      | 我的资料、编辑资料、提交认证、认证状态                       |
| 车辆管理 `vehicle`                | WO01      | 新增/编辑车辆、车辆列表                                      |
| 行程管理 `trip`                   | WO01      | 发布行程、我的行程、更新行程状态                             |
| 接单大厅 `orderHall`              | WO01/WO11 | 待接订单、接单、拒单/取消                                    |
| 定位与轨迹 `location/track`       | WO11      | 位置上报、轨迹回放、订单实时轨迹；生产级还应补 WebSocket/SSE 实时推送 |
| AI 预警 `aiAlerts`                | WO10      | 水情/路线风险预警列表                                        |
| 收入账本 `incomeLedger`           | WO03      | 收入汇总、收入明细、结算记录                                 |
| 今日班次 `todayShuttle`           | WO02      | 今日班次、班次详情、到站/发车状态                            |

### 验收基线：

- 管理后台：**12 个业务模块**
- 乘客端：**9 个功能模块**
- 司机端：**9 个功能模块**
